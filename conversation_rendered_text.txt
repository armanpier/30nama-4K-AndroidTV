---
### 1. Root Cause: Platform Token Mismatch & Session Rejection
**Dual-Key Architecture**:
* The Android TV application communicates with the backend using a dedicated Android TV API key (`VdapnkLG9...`).
* The Desktop/Web client uses a separate API key (`et7bRH...`) which supports different streaming profile endpoints (such as 2160p / 4K).
**Cross-Platform Session Rejection**:
* The login process (`qrlogin_code` and `qrlogin_login`) binds the authenticated session token (`c-token`) specifically to the **Android TV client**.
* When API requests were routed to use the Desktop API key, the backend's `/action/user` endpoint rejected the request with `401/403` because the active session token was issued to a TV client, not a desktop client.
**Kick-Back to Login on Play**:
* When `/action/user` fails, the local app state sets `user = null` and `user_allowed_to_stream = false`.
* The React Native navigation logic on the movie details screen (`Function 59451`) checks:
```javascript
if (user && user.user_allowed_to_stream) {
navigate('VideoPlayer', { id: movie.id, free: movie.options.free_stream });
} else if (movie.options.free_stream) {
navigate('VideoPlayer', { id: movie.id, free: movie.options.free_stream });
} else {
navigate('Login'); // <--- Triggers return to QR screen
}
```
* Because the session check failed cross-validation, pressing play immediately redirected back to the QR login screen.
---
### 2. Binary & Hermes Bytecode (HBC v90) Constraints
**Strict Bytecode Alignment**:
* The application bundle is compiled with Hermes bytecode version 90 (React Native).
* In Hermes bytecode, instruction offsets, string table indices, jump targets, and register pools are fixed. If an instruction length or string offset changes by even a single byte without recalculating the entire binary header, string table, and SHA-1 checksum footer, the Hermes runtime crashes instantly on launch (`EXC_BAD_ACCESS` / `SIGSEGV`).
**Surgical Patching Complexity**:
* To route API keys dynamically (using the TV key for `qrlogin`, `user`, `checks`, and `home`, while only invoking the Desktop key for `action/stream`), bytecode instructions must be replaced in-place without altering function length or invalidating jump tables.
---
